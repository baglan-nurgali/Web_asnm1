## Objective
The objective of this assignment is to build a foundational web page using HTML5 and CSS3, demonstrating skills in:
- HTML structure, headings, lists, tables, images, links, forms, and emojis.
- CSS styling techniques (Inline, Internal, External CSS).
- CSS Selectors (Element, Class `.highlight`, ID `#main-heading`).
- Box Model principles (margin, padding, border), sizing units (`px`, `%`, `em`, `rem`), positioning (`static`, `relative`, `absolute`), and layout formatting (`float` / `clear`).
- Publishing a web application via GitHub Pages.
